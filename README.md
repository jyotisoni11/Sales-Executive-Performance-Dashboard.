# 📊 Sales Executive Performance Dashboard

An interactive **Sales Executive Performance Dashboard built in Microsoft Excel** to analyze sales performance, target achievement, and city-wise sales executive performance.

The dashboard converts sales data into an interactive business reporting solution using **Excel, PivotTables, charts, formulas, dashboard navigation, and VBA/macros**.

---

## 📌 Project Overview

The objective of this project is to build an interactive dashboard that helps analyze the performance of sales executives across different cities.

The dashboard provides multiple views of sales performance, allowing users to compare:

- Total sales generated by each sales executive
- Sales performance across different cities
- Target Hit %
- Away From Target %
- Individual sales executive performance
- Sales contribution by executive
- Performance differences between executives

Users can select different cities and navigate between multiple dashboard views to analyze the data interactively.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze sales executive performance
- Compare total sales generated by executives
- Analyze city-wise sales performance
- Measure target achievement
- Identify performance gaps
- Create an interactive Excel dashboard
- Present business insights using charts and KPIs
- Automate dashboard navigation using VBA/macros

---

## 📊 Dashboard Features

### 🌆 City-Wise Analysis

The dashboard provides city-level analysis for:

- Chennai
- Delhi
- Mumbai
- Nagpur
- Patna
- Pune
- Ranchi
- Surat

Users can select a city to analyze the corresponding sales executive performance.

---

### 👤 Sales Executive Performance

The dashboard displays sales performance for individual executives.

It includes:

- Sales Executive
- Total Sales
- Target Hit %
- Away From Target %

This makes it easier to compare individual performance.

---

### 💰 Total Sales Analysis

The dashboard provides total sales information for each sales executive.

A bar chart is used to visually compare sales performance between executives.

This allows users to quickly identify differences in sales contribution.

---

### 🎯 Target Hit % Analysis

The dashboard includes a **Target Hit %** view to analyze how effectively sales executives are achieving their assigned targets.

This helps answer:

- Which executives are closer to their targets?
- How much of the target has been achieved?
- How does target achievement differ between executives?

---

### 📉 Away From Target % Analysis

The dashboard also tracks **Away From Target %**.

This metric helps identify the gap between an executive's actual performance and their target.

It provides another perspective for understanding sales performance.
